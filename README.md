## Installation Guide

### Option A — Web Installer (Recommended)

1. Upload all files to your hosting `public_html` or server root.
2. Point your domain to the `public/` directory.
3. Visit `https://yourdomain.com/install` in your browser.
4. Follow the 5-step installation wizard:
   - System requirements check
   - Database configuration
   - Admin account creation
   - Application settings
   - Finish & seed demo data
5. After install, the wizard is automatically disabled.

### Option B — CLI Installation

```bash
# 1. Clone / extract to server
cd /var/www/eliteshop

# 2. Install PHP dependencies
composer install --no-dev --optimize-autoloader

# 3. Install Node dependencies & build frontend
npm ci
npm run build

# 4. Copy environment file
cp .env.example .env

# 5. Generate application key
php artisan key:generate

# 6. Configure your .env (see Environment Variables section)

# 7. Run migrations + seed
php artisan migrate --seed

# 8. Set storage permissions
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

# 9. Create storage symlink
php artisan storage:link

# 10. Optimize for production
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

## Queue Setup

OTP emails and payment confirmation emails are queued to prevent blocking HTTP responses.

### Using Redis (Recommended)

```bash
# Start the queue worker (keep it running with Supervisor)
php artisan queue:work redis --sleep=3 --tries=3 --max-time=3600
```

**Supervisor config** (`/etc/supervisor/conf.d/eliteshop-worker.conf`):

```ini
[program:eliteshop-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/eliteshop/artisan queue:work redis --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/log/eliteshop-worker.log
stopwaitsecs=3600
```

```bash
supervisorctl reread
supervisorctl update
supervisorctl start eliteshop-worker:*
```

### Using Database Queue (No Redis)

```dotenv
QUEUE_CONNECTION=database
```

```bash
php artisan queue:table
php artisan migrate
```

## Stripe Setup

1. Log in to [dashboard.stripe.com](https://dashboard.stripe.com)
2. Go to **Developers → API Keys** and copy your keys to `.env`
3. Go to **Developers → Webhooks → Add endpoint**:
   - URL: `https://yourdomain.com/api/v1/webhooks/stripe`
   - Events to listen to: `payment_intent.succeeded`, `payment_intent.payment_failed`, `charge.refunded`
4. Copy the **Signing secret** (`whsec_...`) to `STRIPE_WEBHOOK_SECRET` in `.env`

## Google OAuth Setup

1. Go to [console.cloud.google.com](https://console.cloud.google.com)
2. Create a new project or select an existing one
3. Navigate to **APIs & Services → Credentials**
4. Click **Create Credentials → OAuth 2.0 Client ID** (Application type: Web)
5. Add Authorized redirect URI: `https://yourdomain.com/api/v1/users/google-callback`
6. Copy the Client ID and Secret to your `.env`

## PayPal Setup

1. Log in to [developer.paypal.com](https://developer.paypal.com)
2. Create a new **REST App** under **My Apps & Credentials**
3. Copy the **Client ID** and **Secret** for sandbox/live
4. Webhooks: go to **Webhooks → Add Webhook**:
   - URL: `https://yourdomain.com/api/v1/webhooks/paypal`

## Webhook Setup

All webhook endpoints are **CSRF-exempt** and use signature verification:

| Gateway | Endpoint | Verification Method |
|---------|----------|---------------------|
| Stripe | `POST /api/v1/webhooks/stripe` | HMAC `Stripe-Signature` header |
| Paymob | `POST /api/v1/webhooks/paymob` | HMAC SHA-512 sorted payload |
| MyFatoorah | `POST /api/v1/webhooks/myfatoorah` | HMAC SHA-256 `X-MyFatoorah-Signature` |
| PayPal | `POST /api/v1/webhooks/paypal` | JSON payload validation |

> **Security:** All endpoints return `400 Bad Request` for invalid signatures. Secrets are never exposed in responses.

## Production Deployment

### Nginx Configuration

```nginx
server {
    listen 80;
    server_name yourdomain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yourdomain.com;

    ssl_certificate /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;

    root /var/www/eliteshop/public;
    index index.php;

    # Security headers
    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header X-XSS-Protection "1; mode=block";
    add_header Referrer-Policy "strict-origin-when-cross-origin";

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

### Apache Configuration (`.htaccess` already included in `public/`)

Ensure `mod_rewrite` is enabled:

```bash
a2enmod rewrite
systemctl restart apache2
```

## Security Hardening Guide

1. **Set `APP_DEBUG=false`** in production — never expose stack traces
2. **Rotate `APP_KEY`** if the application was ever committed with a key exposed
3. **Use HTTPS only** — enforce via `FORCE_HTTPS=true` in `.env`
4. **Restrict database user** — grant only `SELECT, INSERT, UPDATE, DELETE` on the app database
5. **Keep dependencies updated:**
   ```bash
   composer audit
   npm audit
   ```
6. **File permissions:**
   ```bash
   find . -type f -exec chmod 644 {} \;
   find . -type d -exec chmod 755 {} \;
   chmod -R 775 storage bootstrap/cache
   ```
7. **Never commit `.env`** — it is already in `.gitignore`
8. **Rate limiting** is enforced on all auth endpoints (OTP, login, registration)
9. **Webhook endpoints** validate signatures — never process unsigned payloads

# 2. Pull latest code
git pull origin main

# 3. Install/update dependencies

### Response Format

All responses follow this envelope:

```json
{
  "success": true,
  "message": "Human-readable message",
  "data": { ... },
  "errors": {}
}
```

Error response:

```json
{
  "success": false,
  "message": "Validation failed.",
  "data": null,
  "errors": {
    "email": ["The email field is required."]
  }
}
```

## Troubleshooting

### "Class not found" after deployment

```bash
composer dump-autoload -o
php artisan optimize:clear
```

### "419 Page Expired" errors

Ensure `SESSION_DRIVER` is set correctly and the session table exists:

```bash
php artisan session:table
php artisan migrate
```

### Emails not sending

1. Verify SMTP credentials in `.env`
2. Check queue worker is running: `php artisan queue:work`
3. Check failed jobs: `php artisan queue:failed`
4. Retry failed jobs: `php artisan queue:retry all`

### Google OAuth redirect mismatch

Ensure `GOOGLE_REDIRECT_URI` in `.env` **exactly** matches the authorized URI in Google Console, including `https://` and no trailing slash.

### Stripe webhook returning 400

1. Verify `STRIPE_WEBHOOK_SECRET` starts with `whsec_`
2. Ensure webhook endpoint is reachable publicly
3. Check Stripe dashboard → Webhooks → event logs for details

### Installer loop (stuck on /install)

```bash
php artisan config:clear
# Ensure INSTALLED=true in .env
```

### Storage images not showing

```bash
php artisan storage:link
chmod -R 775 storage/app/public
```
