📁 PROJECT RULES (UPDATED)

🧠 RESPONSE STYLE

🛡️ NULL SAFETY RULE (NEW 🔥)

Always use optional chaining
Use fallback defaults always
Validate API response shape

📌 VUE NULL SAFETY

Use ?. everywhere
Use ?? for defaults

Example:

item?.id ?? null

Never loop unknown data

Example:

Array.isArray(data) ? data : []

Guard all v-for

Example:

v-for="item in safeList"

Computed safe list

Example:

const safeList = computed(() =>
  Array.isArray(apiData.value) ? apiData.value : []
)

📌 API RESPONSE SAFETY

Expect nested structure

Example:

res?.data?.data ?? []

Never use direct access

❌ res.data
✅ res?.data?.data ?? []

📌 SERVICE SAFETY

Normalize response inside service

Example:

return res?.data?.data ?? []

Never return raw response

📌 TEMPLATE SAFETY

Never access deep مباشرة

✅ item?.user?.id ?? null

📌 STORE / STATE SAFETY

📌 ITERATION RULE

Never spread unknown
